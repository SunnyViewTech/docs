# 動画バッチ処理

MONO は v.260212 以降、動画ファイルのバッチ処理に対応しています。

## 出力 FPS

エクスポートされるファイルのフレームレートは、動画のフレームレートと同じです。動画のフレームレートが整数でない場合（例: 29.97 fps）、最終結果にわずかなずれが生じることがあります。

## 処理時間

ディスク I/O やフレームごとの処理に伴うオーバーヘッドがあるため、処理時間は動画の長さを上回ります。通常は動画の長さの 3〜10 倍程度かかります。実際の処理時間は、動画の解像度、フレームレート、エンコード形式、ハードウェア性能によって異なります。

## オプション

以下のオプションは、バッチ処理中も有効です。

- フェイスキャプチャモジュール
- 保存先
- 出力形式

以下のオプションは自動的に調整されます。

- キャプチャモードは全身モード
- プロファイルは適用されません
