# キャリブレーション

## キャリブレーションの役割

カメラが前後に傾いていると、アバターの姿勢がずれることがあります。キャリブレーションにより、カメラの傾きを補正できます。

また、キャリブレーションでは人物の位置を原点に合わせるため、シーンとの位置合わせがしやすくなります。

さらに、顔の特徴には個人差があり、基準値のずれが表情の検出精度に影響することがあります。キャリブレーションにより、表情の動きをより正確に検出できます。

## キャリブレーションの方法

**キャリブレーション** ボタンをクリックするか、**C** キーを押すとキャリブレーションが始まります。

![](../img/2026_11_03_14_27_07_.png)

キャリブレーション中は、キャプチャエリアの原点に座るか立ち、体と表情の力を抜いて腕を自然に下ろし、正面を向いてください。

カウントダウンが終わり、「キャリブレーション完了」というメッセージが表示されたら、通常のモーションキャプチャを開始できます。

## フレーム内に人がいない状態でのキャリブレーション

キャリブレーション時にフレーム内に誰もいない場合、MONO は映像をもとにカメラの傾きを補正します。この場合、人物の位置と表情はキャリブレーションされません。

## キャリブレーションに失敗する場合

フレーム内に人物がおらず、背景が単色（グリーンバックなど）の場合、MONO は映像からカメラの傾きを判断できないため、キャリブレーションを完了できません。フレーム内に入ってから、もう一度キャリブレーションを行ってください。
