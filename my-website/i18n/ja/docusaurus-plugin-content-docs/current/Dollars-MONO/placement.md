# カメラの設置

1. **キャプチャの原点と範囲を決める**

キャプチャ空間内で演者が立つ原点に印を付け、演者の活動範囲を決めてください。

2. **カメラとの距離を決める**

カメラと演者の距離を調整し、決めた範囲内で演者が動いても常に全身がフレーム内に収まるようにしてください。演者が腕を上げたときにもフレーム内に収まっていることを確認してください。

全身がフレームに収まることを前提として、可能な限りカメラを近づけると、キャプチャの精度とディテールが向上します。

3. **カメラの高さを決める**

演者が原点に立ったときに、アバターの足が自然に地面に接するようにカメラの高さを調整してください。

4. **その他の注意事項**

- 複雑すぎる背景や、気が散るような背景は避けてください。
- 逆光を避け、均一で安定した照明を確保してください。
- 電源ケーブルや接続ケーブルの長さに注意してください。
