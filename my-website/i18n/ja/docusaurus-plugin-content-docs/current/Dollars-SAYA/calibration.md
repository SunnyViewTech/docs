# キャリブレーション

## キャリブレーションの目的

デバイスが前傾や後傾など、一定の角度で傾いていると、アバターの姿勢にもずれが生じる場合があります。キャリブレーションを行うことで、このようなずれを補正できます。

また、顔の特徴や自然な表情には個人差があるため、表情の再現精度に影響する場合があります。キャリブレーションを行うことで、表情の変化をより正確に認識できるようになります。

全身トラッキングモードでは、キャリブレーション時にアバターがシーンの原点に移動するため、シーン内の他のオブジェクトとの位置合わせが容易になります。

## キャリブレーションの方法

画面下部のキャリブレーションボタンをタップして、キャリブレーションを開始します。

![](../img/2026_08_19_10_48_22-SAYA.png)

キャリブレーション中は、体の力を抜き、自然な表情で、両腕を自然に下ろして正面を向いてください。

全身トラッキングモードでは、トラッキング範囲の中央に自然に立ち、頭から足先まで全身が画面内に収まるようにしてください。

カウントダウンが終了し、「キャリブレーション完了」と表示されたら、通常のトラッキングを開始できます。

キャリブレーション中に同じボタンを再度タップすると、キャリブレーションをキャンセルできます。
