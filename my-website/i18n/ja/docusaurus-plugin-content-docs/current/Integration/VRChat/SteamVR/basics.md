# VRChat の基本操作

:::info ご注意
ご使用の前に、[SteamVR はじめに](/steamvr-getstarted) に従って Dollars MoCap の SteamVR ドライバーをインストールし、Dollars MoCap 製品で SteamVR への送信を有効にしてください。
:::

:::warning 警告
VRChat の操作は VR デバイス向けに設計されています。VR デバイスなしで操作するため、操作感がスムーズでない場合があります。あらかじめご了承ください。

操作性は今後も継続して改善していきます。
:::

マウスとキーボードで Avatar の移動や方向転換ができるほか、Avatar の変更や他の World への移動もできます。

## 移動と方向転換

以下のキーで Avatar の移動と方向転換を行います。

| キー | 説明 |
| --- | --- |
| W | 前進 |
| S | 後退 |
| A | 左へ移動 |
| D | 右へ移動 |
| カンマ（,） | 左を向く |
| ピリオド（.） | 右を向く |

## メニュー

Bridge で **マウス＆キーボード操作** をクリックした後、以下の方法で VRChat のメニューを開くことができます。

| メニュー | 開き方 |
| --- | --- |
| クイックメニュー（Quick Menu） | Q を押して開く、または閉じる |
| アクションメニュー（Action Menu） | E を押して開く、または閉じる |
| メインメニュー（Main Menu） | クイックメニューから開く |

メニューを開いたら、マウスでメニュー項目にカーソルを合わせ、左クリックで選択します。操作が終わったら Esc を押してマウス＆キーボード操作を終了すると、頭と両手はモーションキャプチャによる操作に戻ります。

### メインメニュー

クイックメニューを開き、右下の設定ボタンをクリックしてから、右上の拡大ボタンをクリックすると、メインメニューに入ります。

また、クイックメニューのホーム画面（Launch Pad）にある **Avatars** や **Worlds** などのボタンをクリックすると、メインメニューの該当ページに直接移動することもできます。

## Avatar の選択

1. Bridge で **マウス＆キーボード操作** をクリックし、Q を押してクイックメニューを開きます。
2. クイックメニューからメインメニューを開き、**Avatars** ページに移動します。
3. 使用したい Avatar を選択して適用します。

<video controls width="100%">
  <source src="/ja/vrchat-select-avatar.mp4"/>
</video>

## World の選択

1. Bridge で **マウス＆キーボード操作** をクリックし、Q を押してクイックメニューを開きます。
2. クイックメニューからメインメニューを開き、**Worlds** ページに移動します。
3. 行きたい World を選択して入ります。

## よくある質問

### Q や E を押してもメニューが表示されない

SteamVR のシステムメニューが開いている可能性があります。システムメニューは VR View にのみ表示されます。下の動画の右側のウィンドウが VR View です。

Bridge でコントローラーのシステムボタンをクリックしてシステムメニューを閉じてから、もう一度 Q または E を押すと、クイックメニューまたはアクションメニューが正常に開きます。

<video controls width="100%">
  <source src="/ja/vrchat-faq-system-menu.mp4"/>
</video>

### クイックメニューが表示された後に消えてしまう

多くの場合、以前に開いたメニューが閉じられておらず、Avatar の手に付いたままになっていることが原因です。マウス＆キーボード操作中にマウスを下に動かして視点を下げ、Avatar の手にメニューが表示されていないか確認してください。

メニューがある場合は、Bridge でコントローラーのメニューボタンをクリックして閉じてください。複数回クリックが必要な場合があります。閉じた後は、クイックメニューを再び正常に開けるようになります。
