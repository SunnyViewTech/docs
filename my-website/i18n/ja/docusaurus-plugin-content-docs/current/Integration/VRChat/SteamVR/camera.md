# Stream Camera

VRChat ウィンドウには、デフォルトで頭の動きに合わせて動く一人称視点の映像が表示されます。VRChat の Stream Camera を使用すると、固定された三人称視点に切り替えることができ、配信や録画に便利です。

## Stream Camera を開く

1. SteamVR で **Display VR View** を開きます。Stream モードに切り替えると VRChat ウィンドウに一人称視点が表示されなくなるため、VR View で確認しながら操作する必要があります。
2. Bridge で **マウス＆キーボード操作** をクリックし、Q を押してクイックメニューを開きます。
3. カメラを開き、モードを **Stream** に切り替えます。

これで VRChat ウィンドウにカメラの映像が表示されます。引き続き VR View で操作できます。

</video>

## Flying モード

Flying モードをオンにすると、カメラが Avatar から離れて自由に移動できるようになります。三人称視点の撮影に適しています。

1. VR View で、カメラ設定の **Flying** をクリックします。

   <video controls width="100%">
     <source src="/ja/vrchat-stream-camera-flying-on.mp4"/>
   </video>

2. Alt+Tab で VRChat ウィンドウに切り替え、マウスとキーボードでカメラを動かして、適切な位置に調整します。

   <video controls width="100%">
     <source src="/ja/vrchat-stream-camera-flying-move.mp4"/>
   </video>

3. Alt+Tab で Bridge に切り替え、Flying モードをオフにしてから、マウス＆キーボード操作を終了します。これで VRChat ウィンドウには固定された視点の映像が表示され、頭の動きに追従しなくなります。

   <video controls width="100%">
     <source src="/ja/vrchat-stream-camera-flying-off.mp4"/>
   </video>

:::tip ヒント
マウス＆キーボード操作を終了する前に、Flying モードをオフにしてください。順番が逆になると、Avatar の手が下がるのに合わせて Stream Camera の映像が上下逆さまになることがあります。その場合は、もう一度マウス＆キーボード操作に入り、Q を押してカメラ設定を開くと、映像が元に戻ります。

<video controls width="100%">
  <source src="/ja/vrchat-stream-camera-flipped.mp4"/>
</video>
:::
